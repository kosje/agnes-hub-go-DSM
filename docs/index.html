Agnes Hub — 群晖 DSM 套件源

Agnes AI 多账号聚合中转 + RPM 限流排队网关，打包为群晖套件。

添加套件源

群晖的套件源按 CPU 架构区分，请按你的机型选对应地址 （协议里 catalog 条目不含架构字段，架构过滤由服务端做，静态托管只能一架构一份文件）。

你的机型要添加的套件源地址
Intel / AMD 64 位机型（apollolake、avoton、braswell、broadwell、bromolow、cedarview、coffeelake、denverton、geminilake、grantley、kvmx64、purley、skylaked、v1000 等）https://kosje.github.io/agnes-hub-go-DSM/catalog.json
ARM64 机型（rtd1296、rtd1619、rtd1619b、armada37xx，如 DS223 / DS423 系列）https://kosje.github.io/agnes-hub-go-DSM/catalog-armv8.json

在 DSM 里：套件中心 → 设置 → 套件来源 → 新增，把上面的地址粘进去。

如果提示「套件来源不受信任」：到 套件中心 → 设置 → 常规 → 信任层级 选「任何发行者」，再重新添加。 这是第三方未签名套件的统一门槛，与本套件无关。

关于升级

套件由套件中心管理，内置自更新已禁用（启动时带 -no-selfupdate）。 原因是套件的 INFO 里登记了 package.tgz 的 checksum， 若允许进程内替换二进制，套件实际内容就会与已安装版本对不上，下次升级必然冲突。 本套件源会把新版本列进套件中心，直接点「更新」即可。

升级保留数据目录，只有卸载套件才会连同删除。

手动下载

不想加套件源的话，到 Releases 直接下 SPK，用「套件中心 → 手动安装」装。
